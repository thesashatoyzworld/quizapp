   - **System**: 4-step process using `.steps-list`
   - **Week 12**: Stats grid using `.stats-grid` pattern
   - **3 Phases**: Three cards with colored left border (use inline style for phase color)
   - **Tiers**: Two tier cards side-by-side on desktop, stacked on mobile. Basic tier: standard border. Premium tier: highlighted with `--neon-magenta` border + "Рекомендуем" badge.

   - **CTA**: Final call-to-action section. Use `.card-cta` wrapper. CTA button says "ЗАПИСАТЬСЯ" with `.btn-neon`. Button should be a placeholder (no onClick handler yet — payment is Phase 13). Add a note "Оплата будет доступна скоро" below the button.

5. **Mobile-first**: The page must work at 360px width. Use existing responsive breakpoints from globals.css. The tier cards specifically need a custom class to go side-by-side on desktop (>600px) and stack on mobile.

6. **Telegram WebApp SDK**: The page inherits the layout.tsx which already loads the Telegram WebApp script, so no additional setup needed.

7. **Store `type` param for Phase 12**: Accept and validate the `type` query param but don't use it for personalization yet. Just pass it through so it's available. If invalid type provided, default to 'invisible'.
