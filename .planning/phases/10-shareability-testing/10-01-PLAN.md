  <action>
    1. Install html-to-image: `cd quiz-app && npm install html-to-image`

    2. Modify HeroSection.tsx:
       - Accept a new optional prop `heroRef?: React.RefObject<HTMLDivElement | null>` in HeroSectionProps
       - Apply `ref={heroRef}` to the root `.hero-section` div
       - This ref will be used by ShareButton to capture the hero section as screenshot

    3. Create ShareButton.tsx component:
       - Import `toPng` from `html-to-image`
       - Props: `heroRef: React.RefObject<HTMLDivElement | null>`, `resultTitle: string`, `resultId: string`, `accentColor: string`
       - State: `isGenerating` (loading state during screenshot), `shareError` (error message)
       - Screenshot generation function:
         a. Use `toPng(heroRef.current, { quality: 0.95, pixelRatio: 2, backgroundColor: '#0a0612' })` to capture hero as PNG
         b. The hero section is already visually complete with user name, level, financial data
         c. No need for 9:16 container wrapping — hero section is already portrait-oriented and centered
       - Share function:
         a. Generate screenshot PNG as data URL via toPng
         b. Convert data URL to Blob
         c. Use Web Share API if available: `navigator.share({ files: [new File([blob], 'quiz-result.png', { type: 'image/png' })] })`
         d. Fallback for environments without Web Share API: create a temporary download link
         e. For Telegram context specifically: use `navigator.share` (Telegram WebView supports it on mobile)
       - Render: A styled button with share icon and "Поделиться результатом" text
       - Loading state: show spinner/pulse animation while generating
       - Error state: show brief error message that auto-clears after 3 seconds

    4. Add ShareButton to shared/index.ts barrel export

    5. Add CSS to globals.css:
       - `.share-btn` — styled as secondary action button (outlined, matching cyberpunk theme)
       - `.share-btn:active` — pressed state
       - `.share-btn-loading` — pulse animation during generation
       - `.share-btn-icon` — SVG share icon sizing
       - Position: centered, placed between hero section and first content section
       - Mobile responsive at 480px breakpoint

    Do NOT use Telegram MainButton for sharing — it has a fixed position and single-purpose usage.
    Do NOT try to use Telegram Bot API for sending images — this is a client-side share flow.
