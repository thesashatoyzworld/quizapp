# Phase 12.1 Plan 01: Landing Page Content Restructure Summary

**One-liner:** Added 3 new content sections (preQualifier with 5 archetype versions, beliefShift, forYouIf) and updated base copy to reflect program format (weekly calls, individual approach, concrete results)

## Overview

Phase 12.1-01 adds the data layer for the landing page conversion optimization. This plan implemented 3 new content sections with proper type safety and deep merge support, plus updated existing copy to accurately reflect the program format based on user answers.

## What Was Built

### New Content Sections

1. **preQualifier** — Pre-hero qualifier line (personalized per archetype)
   - Base: 'Для экспертов, которые хотят выстроить систему привлечения клиентов...'
   - invisible: 'которых никто не видит онлайн'
   - doer: 'никак не могут собрать всё в работающую систему'
   - generous: 'зарабатывают меньше, чем заслуживают'
   - unstable: 'то густо, то пусто'
   - scale: 'упёрлись в потолок дохода'

2. **beliefShift** — Universal belief shift message (after problem/3-elements)
   - Title: 'Дело не в вас'
   - Subtitle: 'Дело в отсутствии системы'
   - Text: Why system > luck/mood/subscribers
   - Shift: 'Это не курс — совместная работа над вашим проектом в групповом формате'

3. **forYouIf** — Universal self-selection criteria (before final CTA)
   - Title: 'Эта программа для вас, если'
   - 6 items: real skills but chaotic clients, 5-7 hrs/week commitment, need practice not theory, want stable flow not spikes, ready to act, want 12-week results

### Updated Base Copy

**Program format accuracy (reflecting user answers):**

- **threeElements.title**: '3 элемента системы' (shorter, less hype per "прозрачность > пулепробиваемость" decision)
- **firstDays.items**: Updated to reflect weekly calls + individual plan + feedback from market
- **author.description**: Mentions weekly calls, personal review of each project, max 10 people
- **author.facts**: Weekly live calls, individual content review, no assistants
- **week12.subtitle**: 'К концу 12 недель совместной работы у вас есть:'
- **week12.results**: Concrete deliverables (working products, funnel, content system, scripts/lead magnets) instead of vague metrics

## Technical Implementation

### Type Safety
- Updated `ContentOverrides` type to include optional overrides for all 3 new sections

### Deep Merge Support
- `preQualifier`: Simple spread merge (like `important`)

### Archetype Personalization
- Only `preQualifier` is personalized per archetype (5 versions)
- `beliefShift` and `forYouIf` stay universal (base content only)
- Deep merge correctly handles new sections without breaking existing overrides
