    - Latest code deployed to Vercel (quiz.thesashatoyz.com)
    - Open @testtoyzbot on each platform
    - Complete quiz to reach result page

    ## Platform Matrix
    Table with columns: Test Case | iOS Telegram | Android Telegram | Desktop Telegram | Notes

    ## Test Categories:

    ### 1. Hero Section Rendering
    - [ ] User name displayed correctly (from Telegram profile)
    - [ ] Result title and subtitle readable, no text overflow
    - [ ] LevelBadge renders with correct level and glow effect
    - [ ] Financial amount "300 000+ ₽" displayed in red, no line breaks
    - [ ] PDF download link visible and functional
    - [ ] Hero section fits viewport width without horizontal scroll

    ### 2. Share Button
    - [ ] Share button visible below hero section
    - [ ] Share button has correct cyberpunk styling (border, icon)
    - [ ] Tapping share button shows loading state
    - [ ] Screenshot generates successfully (no error message)
    - [ ] Share dialog opens with generated image
    - [ ] Shared image includes: user name, result type, level badge, financial amount
    - [ ] Image quality is acceptable (not blurry, correct colors)
    - [ ] Share button works after scrolling down and back up

    ### 3. Scroll & Animations
    - [ ] AnalyzingLoader shows before result reveal
    - [ ] ScrollReveal animations trigger as user scrolls
    - [ ] Animations are smooth (no jank or stuttering)
    - [ ] Visual accents (accent-quote, accent-number) visible
    - [ ] BeforeAfterComparison renders correctly (side-by-side on desktop, stacked on mobile)

    ### 4. Charts & Diagnostics
    - [ ] Radar chart renders with 5 axes
    - [ ] LevelPath shows 5 levels with current highlighted
    - [ ] FinancialGauge semicircle renders correctly
    - [ ] AudienceDonut renders with correct segments
    - [ ] WeakPointsHighlight shows 2 weak areas
    - [ ] GrowthMetric (Было/Стало) displays correctly

    ### 5. CTA & Payment
    - [ ] CTA card renders with masterclass details
    - [ ] Payment button ("Оплатить") is clickable
    - [ ] Price "3 450 руб" displayed correctly

    ### 6. Overall Layout
    - [ ] No horizontal scrollbar on any section
    - [ ] Text is readable (sufficient contrast, font size)
    - [ ] Spacing between sections is consistent
    - [ ] Bottom of page is reachable by scrolling
    - [ ] Page loads within 3 seconds

    ## Pass/Fail Criteria
    - PASS: All tests pass on all 3 platforms
    - CONDITIONAL PASS: Minor visual differences only (font rendering, shadow intensity)
    - FAIL: Any functional issue (share doesn't work, layout broken, text unreadable)

    ## Issue Template
    For each failing test:
    - Platform:
    - Test case:
    - Expected:
    - Actual:
    - Screenshot: (attach)
